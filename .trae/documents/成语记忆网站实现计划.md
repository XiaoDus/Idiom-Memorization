# 成语记忆网站实现计划

## 1. 项目概述

**项目名称**: 成语记忆大师  
**项目类型**: 交互式成语学习平台  
**核心目标**: 帮助用户通过多种方式高效记忆和理解中文成语  
**目标用户**: 中文学习者、学生、传统文化爱好者

**项目价值**:
- 将枯燥的成语学习转化为有趣的互动体验
- 通过多种记忆方式（闪卡、测验、分类）加深记忆效果
- 提供真实的语境例句，帮助理解和使用成语

## 2. 核心功能设计

### 2.1 首页/成语库页面

**功能模块**:
- **成语分类展示**: 按类别（如"中华文明 传统文化"）分组显示成语
- **成语卡片列表**: 展示成语、含义预览，点击展开完整信息
- **搜索功能**: 支持按成语名称、含义搜索
- **筛选排序**: 按分类筛选、按字母排序

**页面元素**:
- 顶部导航栏（Logo、搜索框、导航链接）
- 分类标签栏（可点击筛选）
- 成语卡片网格（展示成语、简要含义）
- 成语详情模态框/展开面板

### 2.2 闪卡学习模式

**功能设计**:
- **翻转式闪卡**: 正面显示成语，底部显示"显示释义"按钮
- **点击翻转**: 翻转后显示含义和例句
- **记忆反馈**: 提供"认识"和"不认识"两个按钮
- **进度追踪**: 显示当前学习进度（已学习/总成语数）
- **随机顺序**: 随机展示成语，避免固定顺序

**交互流程**:
1. 进入学习模式 → 显示成语
2. 用户思考含义 → 点击"显示释义"
3. 翻转显示含义+例句 → 用户选择"认识/不认识"
4. 自动切换到下一个成语
5. 完成一轮后显示学习报告

### 2.3 测验模式

**功能设计**:
- **选择题模式**: 显示成语，从4个选项中选择正确含义
- **填空题模式**: 给含义，选择正确成语
- **即时反馈**: 选择后立即显示正确/错误
- **得分统计**: 显示本次测验得分和正确率
- **错题回顾**: 记录错题，可单独复习

### 2.4 收藏夹功能

**功能设计**:
- **收藏按钮**: 在成语卡片和详情页提供收藏/取消收藏
- **收藏列表**: 独立页面展示所有收藏的成语
- **本地存储**: 使用 localStorage 保存收藏数据
- **批量操作**: 支持清空收藏

### 2.5 学习进度追踪

**功能设计**:
- **学习记录**: 记录每个成语的学习次数、正确次数
- **掌握度显示**: 用颜色/图标表示掌握程度（未学习/学习中/已掌握）
- **学习统计**: 图表展示学习进度（总学习数、正确率、连续学习天数）
- **数据持久化**: 使用 localStorage 保存进度

## 3. 用户界面设计

### 3.1 设计风格

**整体风格**: 
- 新中式极简风格，融合传统元素和现代设计
- 大量留白，突出内容
- 使用中国传统色系

**配色方案**:
- **主色调**: 朱砂红 `#C73E3A`（传统中国红）
- **辅助色**: 墨色 `#2B2B2B`、宣纸白 `#F8F6F1`
- **强调色**: 金色 `#D4A84B`（用于高亮和装饰）
- **背景色**: 米白 `#FAFAF8`

**字体设计**:
- 标题: 使用衬线体（如思源宋体）体现文化底蕴
- 正文: 使用无衬线体（如思源黑体）保证可读性
- 成语展示: 大号宋体，突出展示效果

**布局风格**:
- 卡片式布局，圆角设计
- 柔和阴影，营造层次感
- 响应式设计，适配桌面和移动端

## 5. 核心功能实现细节

### 5.1 闪卡学习算法

```typescript
// 学习流程
1. 初始化: 随机打乱成语顺序
2. 显示正面（成语）
3. 用户点击 → 翻转显示背面（含义+例句）
4. 用户选择"认识" → 记录正确，移至下一张
5. 用户选择"不认识" → 重新加入队列末尾，稍后再次出现
6. 完成一轮后显示统计报告
```

### 5.2 测验生成算法

```typescript
// 生成选择题
1. 随机选择目标成语作为正确答案
2. 从同一分类中随机选择3个其他成语作为干扰项
3. 如果同分类成语不足，从全部成语中选择
4. 随机打乱选项顺序
5. 确保只有一个正确答案
```

### 5.3 本地存储策略

// localStorage key 设计

- 'idiom-quiz-history': QuizResult[]    // 测验历史
